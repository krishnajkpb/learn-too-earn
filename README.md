### Videos
The Admin panel accepts direct MP4/WebM URLs and attempts to convert Google Drive `/file/d/FILE_ID/view` links to `https://drive.google.com/uc?export=download&id=FILE_ID`.

For Google Drive, set sharing to **Anyone with the link → Viewer** and use an MP4. Direct MP4/WebM URLs are more reliable in an HTML5 player.

### GitHub-only limitation
This is a static GitHub Pages demo. Accounts, approvals, folders and content are stored in browser localStorage, so they are not shared between browsers/devices and are not secure authentication. Large video hosting is also limited by GitHub/Drive/browser constraints.
